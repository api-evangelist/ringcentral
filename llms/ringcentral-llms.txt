# RingCentral

> RingCentral provides unified cloud communications for businesses - voice, video, messaging, contact center, and events. The RingCentral platform API exposes call control, SMS/MMS, fax, voicemail, presence, team messaging, video, analytics, compliance data, and event subscriptions over an OAuth 2.0-secured REST surface (487 operations).

This llms.txt was generated by API Evangelist from the catalog (developers.ringcentral.com publishes no /llms.txt as of 2026-06-20).

## APIs
- [RingCentral Voice API](https://developers.ringcentral.com/voice-api): RingOut, WebRTC, call control, routing, monitoring, conferencing, call log.
- [RingCentral SMS API](https://developers.ringcentral.com/sms-api): targeted and high-volume (A2P 10DLC) SMS/MMS.
- [RingCentral Team Messaging API](https://developers.ringcentral.com/team-messaging-api): chatbots, add-ins, adaptive cards (Glip).
- [RingCentral Video API](https://developers.ringcentral.com/video-api): browser video meetings, recordings, webhooks.
- [RingCentral Fax API](https://developers.ringcentral.com/fax-api): programmable fax send/receive.
- [RingCentral Data / Compliance API](https://developers.ringcentral.com/data-api): bulk export and archival of call/message/video data.
- [RingCentral Audio & Video AI API](https://developers.ringcentral.com/ai-api): speech-to-text, summarization, conversational analytics.
- [RingCentral Contact Center (RingCX) API](https://developers.ringcentral.com/api-reference/Contact-Center): omnichannel agent state, queues, routing, reporting.
- [RingCentral Events API](https://developers.ringcentral.com/api-reference/Events): large-scale virtual/hybrid event lifecycle.
